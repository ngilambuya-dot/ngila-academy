# Computer Hardware

## 🎯 What is Computer Hardware?

**Hardware** refers to the physical parts of a computer that you can see and touch. Hardware works together with software to make a computer function.

---

## 🔑 Main Hardware Components

### 1. CPU (Central Processing Unit)
The "brain" of the computer that processes instructions.

**Key Facts:**
- Processes all calculations
- Measured in GHz (speed)
- Examples: Intel Core i7, AMD Ryzen

### 2. RAM (Random Access Memory)
Temporary memory for running programs.

**Key Facts:**
- Volatile (cleared when powered off)
- Measured in GB
- More RAM = better multitasking

### 3. Hard Drive / SSD
Permanent storage for files and programs.

| Type | Speed | Capacity |
|------|-------|----------|
| **HDD** | Slower | 1TB - 10TB |
| **SSD** | Faster | 256GB - 2TB |

### 4. Motherboard
The main circuit board that connects all components.

**Components on Motherboard:**
- CPU socket
- RAM slots
- PCIe slots (for graphics cards)
- SATA ports (for storage)

### 5. Power Supply Unit (PSU)
Converts electricity from the wall into power for the computer.
