# Computer Software

## 🎯 What is Software?

**Software** is a set of instructions that tells the computer what to do. It is the opposite of hardware (the physical parts).

### Types of Software:
1. **System Software** (Operating Systems)
2. **Application Software** (Programs)
3. **Utility Software** (Maintenance tools)

---

## 🔑 System Software

### Operating System (OS)
The most important software that manages all hardware and software.

**Popular Operating Systems:**
| OS | Company | Device |
|----|---------|--------|
| Windows | Microsoft | PCs |
| macOS | Apple | Macs |
| Linux | Open Source | Servers |
| Android | Google | Mobile |
| iOS | Apple | Mobile |

**OS Functions:**
- Manages memory
- Controls hardware
- Runs applications
- Provides user interface

---

## 📊 Application Software

### Types of Applications:

| Category | Examples |
|----------|----------|
| **Office** | Microsoft Word, Excel, PowerPoint |
| **Web** | Google Chrome, Firefox, Safari |
| **Media** | VLC, Spotify, Photoshop |
| **Programming** | VS Code, PyCharm, Eclipse |
| **Communication** | Zoom, WhatsApp, Slack |

---

## 💡 Utility Software

**Purpose:** Maintain and optimize the computer.

| Utility | Purpose |
|---------|---------|
| Antivirus | Protect from viruses |
| Disk Cleanup | Remove unnecessary files |
| Backup | Save copies of files |
| File Manager | Organize files |

---

## 📊 Summary

### Key Points:
1. **Software** = instructions for the computer
2. **Operating System** = manages everything
3. **Applications** = programs for specific tasks
4. **Utilities** = maintenance tools
