# Functions Review

## 🎯 What is a Function?

A **function** is a relationship where each input has **exactly one** output.

### Key Concept:
> **A function maps every x-value to exactly one y-value.**

### Notation:
f(x) = 2x + 3

text

Read as: "f of x equals 2x plus 3"

---

## 📊 Function Notation

| Notation | Meaning |
|----------|---------|
| f(x) | Function f evaluated at x |
| y = f(x) | y is the output of f at input x |
| f(2) | The value of f when x = 2 |

### Example:
f(x) = x² + 1
f(3) = 3² + 1 = 10
f(-2) = (-2)² + 1 = 5

text

---

## 📊 Domain and Range

### Domain:
> **All possible input values (x-values)** that make the function valid.

### Range:
> **All possible output values (y-values)** that the function can produce.

### Example:
f(x) = x²

Domain: All real numbers (ℝ)
Range: y ≥ 0 (since squares are never negative)

text

### Restrictions:
f(x) = 1/x

Domain: x ≠ 0 (cannot divide by zero)
Range: y ≠ 0

text
f(x) = √x

Domain: x ≥ 0 (cannot take square root of negative)
Range: y ≥ 0

text

## 📊 Types of Functions

### 1. Linear Function
f(x) = mx + c

text
Graph is a straight line.
Example: f(x) = 2x + 3

text

### 2. Quadratic Function
f(x) = ax² + bx + c

text
Graph is a parabola (U-shape).
Example: f(x) = x² - 4x + 3

text

### 3. Cubic Function
f(x) = ax³ + bx² + cx + d

text
Graph has an S-shape.
Example: f(x) = x³ - 2x

text

### 4. Exponential Function
f(x) = aˣ

text
Graph grows/decays rapidly.
Example: f(x) = 2ˣ

text

### 5. Logarithmic Function
f(x) = logₐ(x)

text
Inverse of exponential.
Example: f(x) = log(x)

text

### 6. Trigonometric Functions
f(x) = sin x, cos x, tan x

text
Periodic functions.
Example: f(x) = sin x

text

## ✍️ Worked Examples

### Example 1: Evaluating Functions

**Problem:** If f(x) = 3x - 2, find f(4).

**Solution:**
f(4) = 3(4) - 2 = 12 - 2 = 10

text

---

### Example 2: Finding Domain

**Problem:** Find the domain of f(x) = √(x - 2).

**Solution:**
For the square root to be defined:
x - 2 ≥ 0
x ≥ 2

Domain: [2, ∞)

text

---

### Example 3: Finding Range

**Problem:** Find the range of f(x) = x² + 1.

**Solution:**
Since x² ≥ 0, x² + 1 ≥ 1
Range: [1, ∞)

text

## 🌍 Why This Matters for Calculus

### In calculus, we need functions for:

1. **Limits** → We need functions to find limits
2. **Differentiation** → We differentiate functions
3. **Integration** → We integrate functions
4. **Applications** → Functions model real-world situations
