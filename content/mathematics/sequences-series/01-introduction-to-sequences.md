# Introduction to Sequences

## 🎯 What is a Sequence?

A **sequence** is an ordered list of numbers that follow a specific pattern or rule. Each number in a sequence is called a **term**.

### Key Concept:
> **A sequence is like a list of numbers where each number follows a rule.**

---

## 📊 Key Terminology

| Term | Definition | Example |
|------|------------|---------|
| **Sequence** | Ordered list of numbers | 2, 4, 6, 8, 10 |
| **Term** | Each number in a sequence | 2, 4, 6 |
| **nth Term** | General formula for any term | 2n |
| **First Term** | The first number (a₁) | 2 |
| **Common Difference** | Fixed difference in arithmetic sequences | 2 |
| **Common Ratio** | Fixed ratio in geometric sequences | 2 |

---

## 📊 Types of Sequences

### 1. Arithmetic Sequence
A sequence where the difference between consecutive terms is **constant**.
a, a+d, a+2d, a+3d, ...

text

**Example:** 2, 4, 6, 8, 10
- First term: a = 2
- Common difference: d = 2

### 2. Geometric Sequence
A sequence where the ratio between consecutive terms is **constant**.
a, ar, ar², ar³, ...

text

**Example:** 2, 4, 8, 16, 32
- First term: a = 2
- Common ratio: r = 2

### 3. Fibonacci Sequence
A sequence where each term is the sum of the two previous terms.
1, 1, 2, 3, 5, 8, 13, 21, ...

text

### 4. Square Numbers
1, 4, 9, 16, 25, ...

text

### 5. Cube Numbers
1, 8, 27, 64, 125, ...

text

### 6. Triangular Numbers
1, 3, 6, 10, 15, 21, ...

text

## ✍️ Worked Examples

### Example 1: Finding the nth Term

**Problem:** Find the nth term of the sequence: 3, 5, 7, 9, 11, ...

**Solution:**
Step 1: Identify the pattern
3 → 5 (+2), 5 → 7 (+2), 7 → 9 (+2)

Step 2: First term (a) = 3
Common difference (d) = 2

Step 3: nth term formula
Tₙ = a + (n-1)d
Tₙ = 3 + (n-1)2
Tₙ = 3 + 2n - 2
Tₙ = 2n + 1

text

---

### Example 2: Finding the nth Term

**Problem:** Find the nth term of the sequence: 5, 10, 15, 20, 25, ...

**Solution:**
a = 5, d = 5
Tₙ = 5 + (n-1)5
Tₙ = 5 + 5n - 5
Tₙ = 5n

text

---

### Example 3: Finding Terms from nth Term

**Problem:** If Tₙ = 3n + 2, find the first 5 terms.

**Solution:**
n = 1: T₁ = 3(1) + 2 = 5
n = 2: T₂ = 3(2) + 2 = 8
n = 3: T₃ = 3(3) + 2 = 11
n = 4: T₄ = 3(4) + 2 = 14
n = 5: T₅ = 3(5) + 2 = 17

Sequence: 5, 8, 11, 14, 17

text

---

### Example 4: Finding the nth Term of a Geometric Sequence

**Problem:** Find the nth term of: 2, 6, 18, 54, ...

**Solution:**
Step 1: First term a = 2
Common ratio r = 6/2 = 3

Step 2: nth term formula
Tₙ = arⁿ⁻¹
Tₙ = 2(3)ⁿ⁻¹

## 🌍 Real-Life Applications

### Application 1: Population Growth

> A town has 1000 people. Population grows by 5% each year.
>
> **Sequence:** 1000, 1050, 1102.5, ...
> **This is a geometric sequence!**

### Application 2: Savings

> You save $10 per day, increasing by $2 each day.
>
> **Sequence:** 10, 12, 14, 16, ...
> **This is an arithmetic sequence!**

### Application 3: Building Design

> A staircase has stairs increasing by 2 cm each step.
>
> **Sequence:** 10, 12, 14, 16, ...
> **Arithmetic sequence**
