# Profit, Loss, and Discount

## 🎯 Introduction

In business, understanding profit, loss, and discount is essential. These concepts help businesses determine pricing, calculate earnings, and attract customers.

---

## 📊 Profit and Loss

### Key Terms:

| Term | Definition | Symbol |
|------|------------|--------|
| **Cost Price (CP)** | The amount paid to acquire an item | CP |
| **Selling Price (SP)** | The amount at which an item is sold | SP |
| **Profit** | SP > CP | P |
| **Loss** | SP < CP | L |

### The Rules:
If SP > CP → Profit
If SP < CP → Loss
If SP = CP → No profit, no loss

text

### Formulas:
Profit = SP - CP
Loss = CP - SP

Profit Percentage = (Profit / CP) × 100%
Loss Percentage = (Loss / CP) × 100%

SP = CP + Profit
SP = CP - Loss

text

## ✍️ Worked Examples

### Example 1: Calculating Profit

**Problem:** A trader buys an item for KSh 500 and sells it for KSh 650. Calculate the profit and profit percentage.

**Solution:**
CP = KSh 500
SP = KSh 650

Profit = SP - CP
Profit = 650 - 500 = KSh 150

Profit Percentage = (150 / 500) × 100%
Profit Percentage = 30%

text

---

### Example 2: Calculating Profit Percentage

**Problem:** A trader buys goods worth KSh 1,200 and sells them for KSh 1,500. Find the profit percentage.

**Solution:**
CP = 1,200
SP = 1,500
Profit = 1,500 - 1,200 = 300

Profit Percentage = (300 / 1,200) × 100%
Profit Percentage = 25%

text

---

### Example 3: Calculating Loss

**Problem:** A trader buys a shirt for KSh 800 and sells it for KSh 680. Calculate the loss and loss percentage.

**Solution:**
CP = 800
SP = 680

Loss = CP - SP
Loss = 800 - 680 = KSh 120

Loss Percentage = (120 / 800) × 100%
Loss Percentage = 15%

text

---

### Example 4: Finding Selling Price Given Profit Percentage

**Problem:** A trader buys an item for KSh 400 and wants to make a 20% profit. What should be the selling price?

**Solution:**
CP = 400
Profit Percentage = 20%

Profit = 20% of CP = 0.20 × 400 = 80

SP = CP + Profit
SP = 400 + 80 = 480

text

---

### Example 5: Finding Cost Price Given Selling Price and Loss

**Problem:** An item was sold for KSh 2,400 at a loss of 20%. Find the cost price.

**Solution:**
SP = 2,400
Loss % = 20%
This means SP = 80% of CP

Let CP = x
0.80x = 2,400
x = 2,400 ÷ 0.80
x = 3,000

CP = KSh 3,000

text

## 📊 Discount

### Key Terms:

| Term | Definition |
|------|------------|
| **Marked Price (MP)** | Original price before discount |
| **Discount** | Reduction in price |
| **Discounted Price/Sale Price** | Price after discount |

### Formulas:
Discount = Marked Price × Discount Rate
Sale Price = Marked Price - Discount

Discount Percentage = (Discount / Marked Price) × 100%

text

---

### Example 6: Calculating Discount

**Problem:** A shop sells a TV for KSh 50,000 with a 15% discount. What is the discount amount and the sale price?

**Solution:**
MP = 50,000
Discount % = 15%

Discount = 15% of 50,000
Discount = 0.15 × 50,000 = 7,500

Sale Price = 50,000 - 7,500 = 42,500

text

---

### Example 7: Finding Discount Percentage

**Problem:** A dress originally priced at KSh 4,000 is sold for KSh 3,200. What is the discount percentage?

**Solution:**
MP = 4,000
SP = 3,200

Discount = 4,000 - 3,200 = 800

Discount Percentage = (800 / 4,000) × 100%
Discount Percentage = 20%

text

---

## 💰 Mark-up

### Definition:
> **Mark-up** is the amount added to the cost price to determine the selling price.
Mark-up = SP - CP
Mark-up Percentage = (Mark-up / CP) × 100%

text

### Example 8: Mark-up

**Problem:** A shopkeeper buys a shirt for KSh 600 and marks it up by 25%. What is the selling price?

**Solution:**
CP = 600
Mark-up % = 25%

Mark-up = 25% of 600 = 0.25 × 600 = 150

SP = CP + Mark-up
SP = 600 + 150 = 750

text
