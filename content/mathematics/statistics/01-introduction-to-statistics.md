# Introduction to Statistics

## 🎯 What is Statistics?

**Statistics** is the science of collecting, organizing, analyzing, interpreting, and presenting data.

### Key Concept:
> **Statistics helps us make sense of data and make informed decisions.**

---

## 📊 The Two Main Branches

### 1. Descriptive Statistics
> **Describes and summarizes data using numbers and graphs.**

| Technique | Example |
|-----------|---------|
| Mean (average) | Average test score |
| Median | Middle value |
| Mode | Most common value |
| Charts/Graphs | Bar charts, pie charts |
| Tables | Frequency tables |

### 2. Inferential Statistics
> **Makes predictions and draws conclusions from data.**

| Technique | Example |
|-----------|---------|
| Hypothesis testing | Testing if a drug works |
| Confidence intervals | Estimating population average |
| Regression | Predicting future trends |
| Sampling | Surveying a group to understand a population |

---

## 📊 Types of Data

### By Nature:

| Type | Description | Example |
|------|-------------|---------|
| **Qualitative** | Descriptive, categories | Colors, gender, brands |
| **Quantitative** | Numerical, countable | Age, height, test scores |

### Quantitative Data Types:

| Type | Description | Example |
|------|-------------|---------|
| **Discrete** | Countable, whole numbers | Number of students |
| **Continuous** | Can take any value | Height, weight, temperature |

### Detailed Steps:

**Step 1: Identify the Problem**
- What question do we want to answer?
- What data do we need?

**Step 2: Collect Data**
- How will we collect the data?
- Who will we collect it from?

**Step 3: Organize Data**
- Arrange data in tables
- Group similar data

**Step 4: Analyze Data**
- Calculate summary statistics
- Create graphs and charts

**Step 5: Interpret Results**
- What does the data tell us?
- What conclusions can we draw?

**Step 6: Present Findings**
- Write reports
- Create visualizations
- Explain to others
