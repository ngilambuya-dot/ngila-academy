# Grouped Frequency Distribution

## 🎯 When to Use Grouped Frequency Distribution

### Reasons for Grouping Data:

1. **Large range of scores** (> 15)
2. **Too many individual scores** to list
3. **To simplify interpretation**
4. **To create histograms and frequency polygons**
5. **For sensitive information** (income, age groups)

### Key Concept:
> **Grouped frequency distribution combines several individual scores into class intervals.**

---

## 📊 Steps for Constructing a Grouped Frequency Distribution

### Step 1: Arrange Data

Arrange the data in ascending order.

### Step 2: Find the Range
Range = Highest Score - Lowest Score + 1

text

### Step 3: Determine Number of Classes

**Rule of Thumb:** Between 5 and 20 classes.

### Step 4: Determine Class Interval

**Largest possible:** Range ÷ 12  
**Smallest possible:** Range ÷ 15  
**Choose a convenient integer.**

### Step 5: Create Class Intervals

- Use odd numbers for class intervals
- Start with a multiple of the interval

### Step 6: Tally and Count Frequencies

### Step 7: Complete the Table

- Class Intervals
- Actual Limits
- Midpoints
- Tallies
- Frequency
- Cumulative Frequency
- Percentage Cumulative Frequency

## 📊 Key Components Explained

### Class Interval
The range of scores in each group (e.g., 34-36)

### Actual Limits (Class Boundaries)
The true limits of each class interval.

| Class | Lower Actual Limit | Upper Actual Limit |
|-------|-------------------|-------------------|
| 34-36 | 33.5 | 36.5 |
| 37-39 | 36.5 | 39.5 |

### Midpoint
Midpoint = (Lower Class Limit + Upper Class Limit) / 2

text
Example: (34 + 36) / 2 = 35

### Tally
Counting marks used to count frequencies.

### Frequency (f)
Number of observations in each class.

### Cumulative Frequency (CF)
Running total of frequencies.

### Percentage Cumulative Frequency
%CF = (CF / N) × 100%

## 🎯 Practice Questions

**Question 1:** When should you use a grouped frequency distribution?

<details>
<summary>Click to reveal answer</summary>

When there are many scores (range > 15) or when the distribution is too long and cumbersome.
</details>

---

**Question 2:** How do you calculate the class interval?

<details>
<summary>Click to reveal answer</summary>

Class interval = Range ÷ desired number of classes (usually 5-20 classes)
</details>

---

**Question 3:** What is the midpoint of the class interval 45-49?

<details>
<summary>Click to reveal answer</summary>

(45 + 49) / 2 = 47
</details>

---

**Question 4:** How do you calculate percentage cumulative frequency?

<details>
<summary>Click to reveal answer</summary>

%CF = (CF / N) × 100%
</details>
