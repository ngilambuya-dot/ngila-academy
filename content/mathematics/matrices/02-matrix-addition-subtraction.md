# Matrix Addition and Subtraction

## 🎯 Adding Matrices

### Rule:
> **Matrices can only be added if they have the SAME order.**

To add two matrices, add the corresponding elements (same position).

### Formula:
If A = [aᵢⱼ] and B = [bᵢⱼ] are m × n matrices,
then A + B = [aᵢⱼ + bᵢⱼ]

### Example 1: Adding Matrices

**Problem:** Add A and B.
A = [1 2] B = [5 6]
[3 4] [7 8]

**Solution:**
A + B = [1+5 2+6]
[3+7 4+8]

A + B = [ 6 8]
[10 12]

**Problem:** Can we add A = [1  2] and B = [5  6  7]?

Different orders → CANNOT add!

## 📊 Subtracting Matrices

### Rule:
> **Matrices can only be subtracted if they have the SAME order.**

To subtract matrices, subtract the corresponding elements.

### Formula:
If A = [aᵢⱼ] and B = [bᵢⱼ] are m × n matrices,
then A - B = [aᵢⱼ - bᵢⱼ]

text

---

### Example 4: Subtracting Matrices

**Problem:** Subtract B from A.
A = [1 2] B = [5 6]
[3 4] [7 8]

text

**Solution:**
A - B = [1-5 2-6]
[3-7 4-8]

A - B = [-4 -4]
[-4 -4]

text

## 📊 Scalar Multiplication

### Rule:
> **A scalar is a single number. To multiply a matrix by a scalar, multiply EVERY element by that scalar.**

### Formula:
If A = [aᵢⱼ] and k is a scalar,
then kA = [k × aᵢⱼ]

text

---

### Example 5: Scalar Multiplication

**Problem:** If A = [1  2] and k = 3, find 3A.
                    [3  4]

**Solution:**
3A = [3×1 3×2]
[3×3 3×4]

3A = [3 6]
[9 12]

text

---

### Example 6: Scalar Multiplication

**Problem:** If A = [1  2  3] and k = -2, find -2A.
                    [4  5  6]

**Solution:**
-2A = [-2×1 -2×2 -2×3]
[-2×4 -2×5 -2×6]

-2A = [-2 -4 -6]
[-8 -10 -12]

text

## 📊 Combining Operations

### Example 7: Combined Operations

**Problem:** If A = [1  2] and B = [5  6], find 2A + 3B.
                    [3  4]        [7  8]

**Solution:**
Step 1: 2A = [2 4]
[6 8]

Step 2: 3B = [15 18]
[21 24]

Step 3: 2A + 3B = [2+15 4+18]
[6+21 8+24]

2A + 3B = [17 22]
[27 32]

text

---

### Example 8: Combined Operations

**Problem:** If A = [1  2] and B = [5  6], find 3A - 2B.
                    [3  4]        [7  8]

**Solution:**
Step 1: 3A = [3 6]
[9 12]

Step 2: 2B = [10 12]
[14 16]

Step 3: 3A - 2B = [3-10 6-12]
[9-14 12-16]

3A - 2B = [-7 -6]
[-5 -4]

## 📊 Summary

### Key Rules:

| Operation | Rule | Condition |
|-----------|------|-----------|
| **Addition** | A + B = [aᵢⱼ + bᵢⱼ] | Same order |
| **Subtraction** | A - B = [aᵢⱼ - bᵢⱼ] | Same order |
| **Scalar Multiplication** | kA = [k × aᵢⱼ] | Any matrix |

### Important Properties:
A + B = B + A (Commutative)
A + (B + C) = (A + B) + C (Associative)
A + 0 = A (Identity)
A + (-A) = 0 (Inverse)
k(A + B) = kA + kB (Distributive)
