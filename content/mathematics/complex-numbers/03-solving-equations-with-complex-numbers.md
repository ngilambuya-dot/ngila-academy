# Solving Equations with Complex Numbers

## 🎯 Introduction

### Key Concept:
> **Complex numbers allow us to solve equations that have no real solutions.**

---

## 📊 Quadratic Equations with Complex Roots

### The Quadratic Formula:
For ax² + bx + c = 0:
x = (-b ± √(b² - 4ac))/2a

text

### Discriminant:
D = b² - 4ac

text

| Discriminant | Nature of Roots |
|--------------|-----------------|
| D > 0 | Two distinct real roots |
| D = 0 | One repeated real root |
| D < 0 | Two complex roots (conjugates) |

---

## ✍️ Worked Examples

### Example 1: Complex Roots

**Problem:** Solve x² + 4x + 5 = 0

**Solution:**
Step 1: Identify a = 1, b = 4, c = 5

Step 2: Calculate discriminant
D = 4² - 4(1)(5) = 16 - 20 = -4

Step 3: Apply quadratic formula
x = (-4 ± √(-4))/(2(1))
x = (-4 ± 2i)/2
x = -2 ± i

Therefore: x = -2 + i or x = -2 - i

text

---

### Example 2: Complex Roots

**Problem:** Solve x² - 2x + 5 = 0

**Solution:**
a = 1, b = -2, c = 5

D = (-2)² - 4(1)(5) = 4 - 20 = -16

x = (2 ± √(-16))/2
x = (2 ± 4i)/2
x = 1 ± 2i

x = 1 + 2i or x = 1 - 2i

text

---

### Example 3: Complex Roots

**Problem:** Solve x² + x + 1 = 0

**Solution:**
a = 1, b = 1, c = 1

D = 1 - 4 = -3

x = (-1 ± √(-3))/2
x = (-1 ± i√3)/2

x = -1/2 + (√3/2)i or x = -1/2 - (√3/2)i

text

## 📊 Solving Other Types of Equations

### Example 4: Equation with Complex Coefficients

**Problem:** Solve (1 + i)x + (2 - i) = 3 + 2i

**Solution:**
(1 + i)x = (3 + 2i) - (2 - i)
(1 + i)x = 3 + 2i - 2 + i
(1 + i)x = 1 + 3i

x = (1 + 3i)/(1 + i)
x = (1 + 3i)(1 - i)/(1² + 1²)
x = (1 - i + 3i - 3i²)/2
x = (1 + 2i - 3(-1))/2
x = (1 + 2i + 3)/2
x = (4 + 2i)/2
x = 2 + i

text

---

### Example 5: System of Equations

**Problem:** Solve:
x + yi = 3 + 4i
x - yi = 3 - 4i

text

**Solution:**
Add the equations:
2x = 6 → x = 3

Subtract the equations:
2yi = 8i → y = 4

Answer: x = 3, y = 4

text

## 📊 Fundamental Theorem of Algebra

### The Theorem:
> **Every polynomial of degree n has exactly n complex roots (counting multiplicities).**

### Example:
x³ - 1 = 0
x³ = 1

x = 1, x = (-1 + i√3)/2, x = (-1 - i√3)/2

Three complex roots!

## 📊 Summary

### Key Points:

1. **Quadratic formula** works for all equations, even with negative discriminants
2. **Complex roots** come in conjugate pairs
3. **Fundamental Theorem** guarantees n roots for degree n
4. **Equations** with complex coefficients can be solved algebraically
