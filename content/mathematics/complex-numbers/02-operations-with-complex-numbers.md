# Operations with Complex Numbers

## 🎯 Adding and Subtracting Complex Numbers

### Rule:
> **Add/subtract the real parts and the imaginary parts separately.**
(a + bi) + (c + di) = (a + c) + (b + d)i
(a + bi) - (c + di) = (a - c) + (b - d)i

text

---

## ✍️ Worked Examples

### Example 1: Addition

**Problem:** Add (3 + 4i) and (2 + 5i)

**Solution:**
(3 + 4i) + (2 + 5i) = (3 + 2) + (4 + 5)i
= 5 + 9i

text

---

### Example 2: Subtraction

**Problem:** Subtract (2 + 5i) from (3 + 4i)

**Solution:**
(3 + 4i) - (2 + 5i) = (3 - 2) + (4 - 5)i
= 1 - i

text

---

### Example 3: Mixed Operations

**Problem:** (5 - 3i) + (2 + 7i) - (4 - 2i)

**Solution:**
(5 - 3i) + (2 + 7i) - (4 - 2i)
= (5 + 2 - 4) + (-3 + 7 + 2)i
= 3 + 6i

text

## 📊 Multiplying Complex Numbers

### Rule:
> **Use the distributive property (FOIL) and simplify using i² = -1.**
(a + bi)(c + di) = (ac - bd) + (ad + bc)i

text

### Derivation:
(a + bi)(c + di)
= ac + adi + bci + bdi²
= ac + (ad + bc)i + bd(-1)
= (ac - bd) + (ad + bc)i

text

---

## ✍️ Worked Examples

### Example 4: Multiplying

**Problem:** (3 + 4i)(2 + 5i)

**Solution:**
(3 + 4i)(2 + 5i) = (3×2 - 4×5) + (3×5 + 4×2)i
= (6 - 20) + (15 + 8)i
= -14 + 23i

text

---

### Example 5: Multiplying

**Problem:** (5 - 3i)(2 + 4i)

**Solution:**
(5 - 3i)(2 + 4i) = (5×2 - (-3)×4) + (5×4 + (-3)×2)i
= (10 + 12) + (20 - 6)i
= 22 + 14i

text

---

### Example 6: Squaring

**Problem:** (3 + 4i)²

**Solution:**
(3 + 4i)² = (3 + 4i)(3 + 4i)
= (3×3 - 4×4) + (3×4 + 4×3)i
= (9 - 16) + (12 + 12)i
= -7 + 24i

text

## 📊 Dividing Complex Numbers

### Rule:
> **To divide by a complex number, multiply numerator and denominator by the conjugate of the denominator.**
(a + bi)/(c + di) = (a + bi)(c - di)/(c² + d²)

text

### Steps:
1. Multiply numerator and denominator by conjugate
2. Expand and simplify
3. Write in standard form

---

## ✍️ Worked Examples

### Example 7: Dividing

**Problem:** (3 + 4i)/(2 + 5i)

**Solution:**
Step 1: Multiply by conjugate (2 - 5i)
(3 + 4i)(2 - 5i) / (2 + 5i)(2 - 5i)

Step 2: Numerator
(3 + 4i)(2 - 5i) = (3×2 - 4×(-5)) + (3×(-5) + 4×2)i
= (6 + 20) + (-15 + 8)i
= 26 - 7i

Step 3: Denominator
(2 + 5i)(2 - 5i) = 2² + 5² = 4 + 25 = 29

Step 4: Write in form a + bi
(26 - 7i)/29 = 26/29 - (7/29)i

text

---

### Example 8: Dividing

**Problem:** (1 + i)/(1 - i)

**Solution:**
(1 + i)(1 + i) / (1 - i)(1 + i)

Numerator: (1 + i)² = 1 + 2i + i² = 1 + 2i - 1 = 2i
Denominator: 1² + 1² = 2

Answer: i

text

## 📊 Modulus of a Complex Number

### Definition:
> **The modulus of z = a + bi is the distance from the origin to the point (a,b).**
|z| = √(a² + b²)

text

### Properties:
|z| = |z̄|
|zw| = |z||w|
|z/w| = |z|/|w|

text

---

## ✍️ Worked Examples

### Example 9: Finding Modulus

**Problem:** Find the modulus of z = 3 + 4i

**Solution:**
|z| = √(3² + 4²) = √(9 + 16) = √25 = 5

text

---

### Example 10: Finding Modulus

**Problem:** Find the modulus of z = 5 - 12i

**Solution:**
|z| = √(5² + (-12)²) = √(25 + 144) = √169 = 13

text
