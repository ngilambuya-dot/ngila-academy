# Applications of Complex Numbers

## 🎯 Introduction

### Key Concept:
> **Complex numbers are not just mathematical abstractions—they have real-world applications!**

---

## 📊 Electrical Engineering

### AC Circuits:

In alternating current (AC) circuits, complex numbers are used to represent:
- **Impedance:** Z = R + iX
  - R = Resistance (real part)
  - X = Reactance (imaginary part)

### Example:
If R = 4Ω and X = 3Ω,
Z = 4 + 3i
|Z| = √(16 + 9) = 5Ω

text

---

## 📊 Physics

### Quantum Mechanics:

Complex numbers are fundamental to quantum mechanics.
- **Wave Function:** ψ = A + iB
- **Probability:** |ψ|² = A² + B²

### Example:
If ψ = 3 + 4i,
Probability = |ψ|² = 9 + 16 = 25

text

---

## 📊 Signal Processing

### Fourier Transform:

Complex numbers are used in Fourier transforms for:
- Audio processing
- Image processing
- Signal analysis

### Example:
A signal can be represented as:
f(t) = Σ cₙ e^{int}

Where cₙ are complex coefficients.

text

## 📊 Fractals

### Mandelbrot Set:

The Mandelbrot set is defined using complex numbers:
z_{n+1} = z_n² + c

text

Where z and c are complex numbers.

### Example:
Start with z₀ = 0
For c = i:
z₁ = 0² + i = i
z₂ = i² + i = -1 + i
z₃ = (-1 + i)² + i = -2i + i = -i
...

text

## 📊 Fluid Dynamics

### Complex Potential:

Complex numbers are used to model:
- Fluid flow
- Airflow around objects
- Water waves

### Example:
F(z) = z + 1/z

text
This models flow around a cylinder.

## ✍️ Worked Examples

### Example 1: Electrical Circuit

**Problem:** A circuit has resistance 6Ω and reactance 8Ω. Find the impedance and its magnitude.

**Solution:**
Z = 6 + 8i
|Z| = √(36 + 64) = √100 = 10Ω

text

---

### Example 2: Probability in Quantum Mechanics

**Problem:** A quantum system has wave function ψ = 2 + 3i. Find the probability of finding the particle.

**Solution:**
|ψ|² = 2² + 3² = 4 + 9 = 13
Probability = 13 (up to normalization)

text
