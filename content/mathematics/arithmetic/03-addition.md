# Addition: Basic Operations

## 🎯 What is Addition?

**Addition** is the process of combining two or more numbers to find their total.

### Key Terms:
- **Addends** = numbers being added
- **Sum** = the result of addition
3 + 5 = 8
↑ ↑ ↑
Addend Sum

text

### Plus Sign (+)
The + symbol means "plus" or "add."

---

## 📊 Addition Properties

| Property | Rule | Example |
|----------|------|---------|
| **Commutative** | Order doesn't matter | 3 + 5 = 5 + 3 |
| **Associative** | Grouping doesn't matter | (3 + 5) + 2 = 3 + (5 + 2) |
| **Identity** | Adding zero doesn't change | 5 + 0 = 5 |
| **Inverse** | Adding a number and its negative gives zero | 5 + (-5) = 0 |

## 🔢 Addition Without Carrying

### Steps:
1. Write numbers aligned by place value
2. Add each column starting from the right
3. Write the sum in the same place value

### Example 1: Simple Addition

**Problem:** Add 23 and 45

**Solution:**
23

45
────
68

text

**Step-by-Step:**
- Units: 3 + 5 = 8
- Tens: 2 + 4 = 6
- Answer: 68

---

### Example 2: Three-Digit Addition

**Problem:** Add 234 and 345

**Solution:**
234

345
────
579

text

**Step-by-Step:**
- Units: 4 + 5 = 9
- Tens: 3 + 4 = 7
- Hundreds: 2 + 3 = 5
- Answer: 579

---

## 🔢 Addition With Carrying

### Steps:
1. Add units column
2. If sum > 9, carry the tens digit to the next column
3. Continue with each column

### Example 3: Carrying

**Problem:** Add 48 and 37

**Solution:**
48

37
────
85

text

**Step-by-Step:**
- Units: 8 + 7 = 15
- Write 5, carry 1
- Tens: 4 + 3 + 1 (carry) = 8
- Answer: 85

---

### Example 4: Multiple Carries

**Problem:** Add 789 and 654

**Solution:**
789

654
────
1443

text

**Step-by-Step:**
- Units: 9 + 4 = 13
- Write 3, carry 1
- Tens: 8 + 5 + 1 = 14
- Write 4, carry 1
- Hundreds: 7 + 6 + 1 = 14
- Answer: 1,443

## 🔢 Adding Decimals

### Steps:
1. Align decimal points
2. Add zeros if needed
3. Add as normal
4. Place decimal point in same position

### Example 5: Adding Decimals

**Problem:** Add 4.56 and 2.34

**Solution:**
4.56

2.34
────
6.90

text

**Step-by-Step:**
- Hundredths: 6 + 4 = 10
- Write 0, carry 1
- Tenths: 5 + 3 + 1 = 9
- Units: 4 + 2 = 6
- Answer: 6.90 or 6.9

## 🔢 Adding Integers

### Rule: Add the absolute values and keep the sign

| Same Sign | Different Signs |
|-----------|-----------------|
| 5 + 3 = 8 | 5 + (-3) = 2 |
| -5 + (-3) = -8 | -5 + 3 = -2 |

### Example 8: Adding Positive Integers

## 🔢 Addition in Different Number Bases

### Example 12: Binary Addition (Base 2)

**Problem:** Add 101₁₀ and 11₁₀ in binary

**Solution:**
101₂

11₂
────
1000₂

Step-by-Step:

Units: 1 + 1 = 10₂ (write 0, carry 1)

Twos: 0 + 1 + 1 = 10₂ (write 0, carry 1)

Fours: 1 + 0 + 1 = 10₂ (write 0, carry 1)

Eights: 0 + 0 + 1 = 1

Answer: 1000₂ (which is 8 in decimal)

## 🌍 Real-Life Applications

### Application 1: Shopping

> You buy items costing $12.50, $8.75, and $5.25.
>
> **Total:** $12.50 + $8.75 + $5.25 = $26.50

### Application 2: Distance

> You walk 2.5 km, then 1.8 km, then 3.2 km.
>
> **Total distance:** 2.5 + 1.8 + 3.2 = 7.5 km

### Application 3: Temperature

> Temperature rises from 18°C to 25°C.
>
> **Increase:** 25 - 18 = 7°C

## 🚨 Common Mistakes

### Mistake 1: Forgetting to Carry

| ❌ WRONG | ✅ CORRECT |
|----------|-----------|
| 48 + 37 = 75 | 48 + 37 = 85 |

---

### Mistake 2: Misaligning Decimal Points

| ❌ WRONG | ✅ CORRECT |
|----------|-----------|
| 3.4 + 2.56 = 5.90 | 3.40 + 2.56 = 5.96 |

---

### Mistake 3: Sign Errors

| ❌ WRONG | ✅ CORRECT |
|----------|-----------|
| -5 + (-8) = 13 | -5 + (-8) = -13 |

---

## 📊 Summary

### Key Points:

1. **Addition** = combining numbers to find total
2. **Align** place values and decimal points
3. **Carry** when column sum > 9
4. **Signs:** Same signs add, different signs subtract
5. **Check** your work by subtracting

### Addition Vocabulary:
- **Addend:** number being added
- **Sum:** result of addition
- **Carry:** moving a digit to the next column
