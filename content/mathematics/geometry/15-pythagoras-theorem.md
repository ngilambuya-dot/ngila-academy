# Pythagoras' Theorem

## 🎯 What is Pythagoras' Theorem?

**Pythagoras' Theorem** states that in a right-angled triangle, the square of the hypotenuse is equal to the sum of the squares of the other two sides.

### The Formula:
a² + b² = c²

text

Where:
- **c** = hypotenuse (the longest side, opposite the right angle)
- **a** and **b** = the other two sides (legs)

|
|
a | \ c (hypotenuse)
|
|____
B b C

## 📊 Identifying the Hypotenuse

### Rule:
> The **hypotenuse** is always the side **opposite the right angle**. It is the **longest side**.
A
|
| \
| \ ← Hypotenuse
| \ (opposite the right angle)
|____
B C
↑
Right angle

---

## 📊 Finding the Hypotenuse

### Formula:
c = √(a² + b²)

text

### Example 1: Finding Hypotenuse

**Problem:** In a right-angled triangle, a = 3 cm, b = 4 cm. Find c.

**Solution:**
c² = a² + b²
c² = 3² + 4²
c² = 9 + 16
c² = 25
c = √25 = 5 cm

text

---

## 📊 Finding a Shorter Side

### Formula:
a = √(c² - b²)
b = √(c² - a²)

text

### Example 2: Finding a Shorter Side

**Problem:** In a right-angled triangle, c = 13 cm, a = 5 cm. Find b.

**Solution:**
b² = c² - a²
b² = 13² - 5²
b² = 169 - 25
b² = 144
b = √144 = 12 cm

text

---

## 📊 Converse of Pythagoras' Theorem

### The Rule:
> **If a² + b² = c², then the triangle is right-angled.**

### Example 3: Testing for a Right Angle

**Problem:** A triangle has sides 6 cm, 8 cm, 10 cm. Is it right-angled?

**Solution:**
a = 6, b = 8, c = 10
a² + b² = 6² + 8² = 36 + 64 = 100
c² = 10² = 100
Since a² + b² = c², the triangle is right-angled.

text

## 📊 Pythagorean Triples

A **Pythagorean triple** is a set of three integers that satisfy a² + b² = c².

### Common Triples:

## ✍️ Worked Examples

### Example 4: Real-Life Application

**Problem:** A ladder 10 m long is placed against a wall. The foot of the ladder is 6 m from the wall. How high up the wall does the ladder reach?

**Solution:**
Let x = height up the wall
x² + 6² = 10²
x² + 36 = 100
x² = 64
x = √64 = 8 m

text

### Example 5: Diagonal of a Rectangle

**Problem:** A rectangle has length 12 cm and width 5 cm. Find the diagonal.

**Solution:**
Diagonal² = 12² + 5²
Diagonal² = 144 + 25
Diagonal² = 169
Diagonal = √169 = 13 cm

text

### Example 6: Distance in 3D

**Problem:** A cuboid has length 6 cm, width 3 cm, height 4 cm. Find the space diagonal.

**Solution:**
Step 1: Find base diagonal (d)
d² = 6² + 3² = 36 + 9 = 45
d = √45

Step 2: Find space diagonal (D)
D² = d² + h² = 45 + 16 = 61
D = √61 ≈ 7.81 cm

text
