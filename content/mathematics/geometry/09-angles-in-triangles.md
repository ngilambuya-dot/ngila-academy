# Angles in Triangles

## 🎯 What is a Triangle?

A **triangle** is a polygon with **three sides** and **three angles**.

### Key Properties:
- ✅ A triangle has **3 sides**, **3 vertices**, and **3 angles**
- ✅ The sum of the interior angles is **always 180°**
- ✅ It is the **simplest polygon**

## 📊 Angle Sum of a Triangle

### The Most Important Rule:

> **The sum of the interior angles of a triangle is 180°.**
∠A + ∠B + ∠C = 180°

/
/

text

### Proof:

**Given:** Triangle ABC

**To Prove:** ∠A + ∠B + ∠C = 180°

**Construction:** Draw a line through A parallel to BC
A ──┬───────
│
B │ C
────┼───────

text

**Proof:**
1. ∠B = ∠1 (Alternate interior angles)
2. ∠C = ∠2 (Alternate interior angles)
3. ∠1 + ∠A + ∠2 = 180° (Angles on a straight line)
4. Therefore, ∠B + ∠A + ∠C = 180°

## 📊 Exterior Angle Theorem

### The Rule:

> **An exterior angle of a triangle is equal to the sum of the two opposite interior angles.**
Exterior Angle = ∠A + ∠B

text

**Formula:**
∠ACD = ∠A + ∠B

text

### Proof:

**Given:** Triangle ABC with exterior angle ACD

**To Prove:** ∠ACD = ∠A + ∠B

**Proof:**
1. ∠A + ∠B + ∠C = 180° (Angle sum of triangle)
2. ∠ACD + ∠C = 180° (Angles on a straight line)
3. ∠A + ∠B + ∠C = ∠ACD + ∠C
4. ∠A + ∠B = ∠ACD

## 📊 Isosceles Triangle Properties

### The Rules:

> **In an isosceles triangle:**
> 1. Base angles are equal
> 2. Sides opposite equal angles are equal
A
/
/
/
B /______\ C

text

**Formula:**
∠B = ∠C
AB = AC

text

### Example: Isosceles Triangle

**Problem:** In an isosceles triangle, the vertex angle is 40°. Find the base angles.

**Solution:**
∠A = 40° (Vertex angle)
∠B = ∠C (Base angles are equal)
∠A + ∠B + ∠C = 180°
40° + 2∠B = 180°
2∠B = 140°
∠B = 70°

text

### Example 3: Isosceles Triangle

**Problem:** In an isosceles triangle, the base angles are each 65°. Find the vertex angle.

**Solution:**
∠B = 65°, ∠C = 65°
∠A + 65° + 65° = 180°

**Question 5:** In an isosceles triangle, the base angles are each 2x + 10° and the vertex angle is 4x - 20°. Find all angles.

<details>
<summary>Click to reveal answer</summary>

2(2x + 10) + (4x - 20) = 180°

Vertex angle = 4(22.5) - 20 = 70°
