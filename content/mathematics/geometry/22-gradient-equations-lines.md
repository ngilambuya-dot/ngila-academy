# Gradient and Equations of Lines

## 🎯 What is Gradient?

**Gradient** (also called slope) measures how steep a line is. It tells us the rate of change of y with respect to x.

### Key Concept:
> **Gradient = change in y / change in x**
m = (y₂ - y₁) / (x₂ - x₁)

text

**In simple terms:**
m = rise / run

text

## ✍️ Worked Examples

### Example 1: Finding Gradient

**Problem:** Find the gradient between A(2,3) and B(6,11).

**Solution:**
m = (y₂ - y₁) / (x₂ - x₁)
m = (11 - 3) / (6 - 2)
m = 8 / 4
m = 2

text

**Answer:** m = 2 (rises 2 units for every 1 unit right)

---

### Example 2: Finding Gradient (Negative)

**Problem:** Find the gradient between A(2,6) and B(5,3).

**Solution:**
m = (3 - 6) / (5 - 2)
m = -3 / 3
m = -1

text

**Answer:** m = -1 (falls 1 unit for every 1 unit right)

## 📊 Equation of a Straight Line

### Slope-Intercept Form:
y = mx + c

text

Where:
- m = gradient
- c = y-intercept (where the line crosses the y-axis)

### Example 3: Finding Equation

**Problem:** Find the equation of a line with gradient 2 and y-intercept 3.

**Solution:**
y = mx + c
y = 2x + 3

text

---

### Example 4: Finding Equation from Two Points

**Problem:** Find the equation of the line through A(2,3) and B(4,7).

**Solution:**
Step 1: Find gradient
m = (7 - 3) / (4 - 2) = 4/2 = 2

Step 2: Find c using one point
y = 2x + c
3 = 2(2) + c
3 = 4 + c
c = -1

Step 3: Write equation
y = 2x - 1

text

## 📊 Gradient and Angle

### Relationship:
> **m = tan θ**

Where θ is the angle the line makes with the positive x-axis.
y
↑
│
│ / θ
│ /
│ /
│ /
│/

text

### Example 5: Finding Angle

**Problem:** A line has gradient m = 1. Find the angle θ.

**Solution:**
m = tan θ
1 = tan θ
θ = tan⁻¹(1)
θ = 45°

text

### Example 6: Finding Angle

**Problem:** A line has gradient m = √3. Find the angle θ.

**Solution:**
m = tan θ
√3 = tan θ
θ = tan⁻¹(√3)
θ = 60°

text

### Example 7: Finding Gradient from Angle

**Problem:** A line makes an angle of 30° with the x-axis. Find its gradient.

**Solution:**
m = tan θ
m = tan 30°
m = 1/√3

text

## 📊 Parallel and Perpendicular Lines

### Parallel Lines:
> **Parallel lines have the SAME gradient.**
m₁ = m₂

text

### Perpendicular Lines:
> **The product of perpendicular gradients = -1.**
m₁ × m₂ = -1

text

### Example 8: Parallel Lines

**Problem:** Find the equation of a line parallel to y = 2x + 3 that passes through (0,5).

**Solution:**
Parallel lines have same gradient: m = 2
Using y = mx + c:
5 = 2(0) + c
c = 5
y = 2x + 5

text

### Example 9: Perpendicular Lines

**Problem:** Find the gradient perpendicular to m = 2.

**Solution:**
m₁ × m₂ = -1
2 × m₂ = -1
m₂ = -1/2

text

## 📊 Summary

### Key Formulas:

| Concept | Formula |
|---------|---------|
