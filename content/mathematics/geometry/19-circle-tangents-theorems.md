# Circle Tangents and Theorems

## 🎯 What is a Tangent?

A **tangent** to a circle is a straight line that touches the circle at exactly **one point**.

### Key Concept:
> **A tangent touches the circle at exactly one point, called the point of contact.**

## 📊 Theorem 1: Tangent-Radius Theorem

### The Rule:
> **The radius drawn to the point of contact is perpendicular to the tangent.**
● (Centre O)
/
/
/
A───●───B
|
| (Tangent)
C
↑
Point of contact

text

**Formula:**
OA ⟂ TC (where T is the point of tangency)

text

**Angle:**
∠OAT = 90°

text

### Proof:

**Given:** Circle with centre O, tangent TC at point T

**To Prove:** OT ⟂ TC

**Proof:**
1. Suppose OT is not perpendicular to TC
2. Then there would be another point on TC closer to O than T
3. This would mean the line TC cuts the circle at another point
4. This contradicts the definition of a tangent
5. Therefore, OT ⟂ TC
∠OTP = 90°

text

## 📊 Theorem 2: Tangents from an External Point

### The Rule:
> **Tangents drawn from the same external point to a circle have equal lengths.**
● (Centre O)
/
/
/
A───●───B
\ /
\ /
\ /
C (External point)

text

**Formula:**
CA = CB

text

**Example:** If CA = 5 cm, then CB = 5 cm.

### Proof:

**Given:** Circle with centre O, external point C, tangents CA and CB

**To Prove:** CA = CB

**Proof:**
1. ∠OAC = 90° (Tangent-radius theorem)
2. ∠OBC = 90° (Tangent-radius theorem)
3. OA = OB (Radii of the same circle)
4. OC is common
5. ∆OAC ≅ ∆OBC (RHS congruence)
6. Therefore, CA = CB (Corresponding sides)

## 📊 Theorem 3: Alternate Segment Theorem

### The Rule:
> **The angle between a tangent and a chord is equal to the angle in the alternate segment.**
● (Centre O)
/
/
/
A───●───B
|
| (Tangent)
C

text

**Formula:**
∠TCB = ∠CAB (alternate segment)

text

### Proof:

**Given:** Circle with tangent TC at C, chord CB

**To Prove:** ∠TCB = ∠CAB

**Proof:**
1. ∠ACB = 90° (Angle in a semicircle)
2. ∠TCB = 90° (Tangent-radius theorem)
3. ∠TCB = ∠CAB + ∠ABC (Exterior angle theorem)
4. ∠CAB = ∠TCB (Alternate segment)

## ✍️ Worked Examples

### Example 1: Tangent-Radius

**Problem:** Find ∠OTP if OT is radius and TP is tangent.

**Solution:**
∠OTP = 90° (Radius perpendicular to tangent at point of contact)

text

### Example 2: Tangents from External Point

**Problem:** From point P outside a circle, two tangents PA and PB are drawn to the circle. If PA = 8 cm, find PB.

**Solution:**
PA = PB (Tangents from an external point are equal)
PB = 8 cm

text

### Example 3: Alternate Segment

**Problem:** ∠CTB = 40° (where CT is tangent). Find ∠CAB.

**Solution:**
∠CAB = ∠CTB = 40° (Alternate segment theorem)

text

### Example 4: Combining Theorems

**Problem:** In the diagram, O is the centre of the circle. PA and PB are tangents. ∠APB = 60°. Find ∠AOB.

**Solution:**
∠OAP = 90° (Tangent-radius theorem)
∠OBP = 90° (Tangent-radius theorem)
∠APB = 60° (Given)

In quadrilateral OAPB:
∠OAP + ∠OBP + ∠APB + ∠AOB = 360°
90° + 90° + 60° + ∠AOB = 360°
240° + ∠AOB = 360°
∠AOB = 120°
