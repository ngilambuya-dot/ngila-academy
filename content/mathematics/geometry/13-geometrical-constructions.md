Geometrical Constructions
🎯 What are Geometrical Constructions?
Geometrical constructions are drawings made using only a compass, a ruler, and a protractor. No measuring is allowed once you start!

Tools:
✅ Ruler (for drawing straight lines)

✅ Compass (for drawing circles and arcs)

✅ Protractor (for measuring and drawing angles)

✅ Pencil (for accuracy)

Key Rule:
You can't measure! Use only the tools for drawing.

📊 Basic Construction Skills
1. Drawing a Straight Line
Use a ruler to draw a straight line.

2. Drawing a Circle/Arc
Use a compass to draw a circle or part of a circle.

3. Measuring an Angle
Use a protractor to measure the size of an angle.

4. Drawing an Angle
Use a protractor to draw an angle of a given size.

📊 Constructing a Perpendicular Bisector
The Task:
Construct the perpendicular bisector of a line segment AB.

Steps:
text
Step 1: Draw line segment AB.

A────────────────────B

Step 2: Place compass at A, radius more than half AB. Draw an arc.

        ┌────────────┐
       /              \
      /                \
     A────────────────────B
      \                /
       \              /
        └────────────┘

Step 3: Place compass at B, same radius. Draw another arc.

        ┌────────────┐
       /   ┌────┐    \
      /   /      \    \
     A───┼────────────B
      \   \      /    /
       \   └────┘    /
        └────────────┘

Step 4: The arcs intersect at two points. Draw a line through them.
        This is the perpendicular bisector.

        ┌────────────┐
       /   ┌────┐    \
      /   /      \    \
     A───┼────────────B
      \   \      /    /
       \   └────┘    /
        └────────────┘
           │  │
           │  │ (Perpendicular bisector)

📊 Loci
What is a Locus?
A locus is the set of all points that satisfy a given condition.

Common Loci:
Locus of a point equidistant from two fixed points

The perpendicular bisector of the line segment joining the two points

Locus of a point equidistant from two intersecting lines

The angle bisector of the angle formed by the lines

Locus of a point at a fixed distance from a fixed point

A circle with the fixed point as centre

Locus of a point at a fixed distance from a line

Two parallel lines on either side of the given line

🌍 Real-Life Applications
Application 1: Engineering
Construction techniques are used in building design.

Application: Perpendicular lines for walls.

Application 2: Navigation
Loci are used in GPS and navigation.

Application: Finding positions.

Application 3: Art and Design
Geometric patterns use constructions.

Application: Islamic geometric art.
