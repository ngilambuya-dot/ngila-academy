Coordinate Geometry
🎯 What is Coordinate Geometry?
Coordinate geometry is the study of geometry using a coordinate system. Points are located using ordered pairs (x, y).

The Cartesian Plane:
text
                    y
                    ↑
       Quadrant II  │  Quadrant I
           (-,+)    │    (+,+)
                    │
    ────────────────┼───────────────→ x
                    │
       Quadrant III │  Quadrant IV
           (-,-)    │    (+,-)
                    │
                    ↓
                    y
Coordinates:
text
(x, y)  where:
- x = horizontal position (left/right)
- y = vertical position (up/down)

📊 Distance Between Two Points
Formula:
text
d = √[(x₂ - x₁)² + (y₂ - y₁)²]
Example 1: Finding Distance
Problem: Find the distance between A(2,3) and B(5,7).

Solution:

text
d = √[(5 - 2)² + (7 - 3)²]
d = √[3² + 4²]
d = √[9 + 16]
d = √25 = 5 units
📊 Midpoint of a Line Segment
Formula:
text
M = ((x₁ + x₂)/2, (y₁ + y₂)/2)
Example 2: Finding Midpoint
Problem: Find the midpoint of A(2,3) and B(6,9).

Solution:

text
M = ((2 + 6)/2, (3 + 9)/2)
M = (8/2, 12/2)
M = (4, 6)
📊 Gradient of a Line
Formula:
text
m = (y₂ - y₁) / (x₂ - x₁)
Where m = gradient

Types of Gradients:
m	Line Direction
Positive	Slopes up to the right
Negative	Slopes down to the right
0	Horizontal line
Undefined	Vertical line
text
Positive Gradient     Negative Gradient     Zero Gradient
    /                    \                    ─────
   /                      \                  
  /                        \                 
 /                          \                
Example 3: Finding Gradient
Problem: Find the gradient of the line through A(2,3) and B(5,9).

Solution:

text
m = (9 - 3) / (5 - 2)
m = 6 / 3 = 2
📊 Equation of a Line
Slope-Intercept Form:
text
y = mx + c
Where:

m = gradient

c = y-intercept (where the line crosses the y-axis)

General Form:
text
ax + by + c = 0
Example 4: Finding Equation
Problem: Find the equation of a line with gradient 2 and y-intercept 3.

Solution:

text
y = mx + c
y = 2x + 3
Example 5: Finding Equation from Two Points
Problem: Find the equation of the line through A(2,3) and B(4,7).

Solution:

text
Step 1: Find gradient
m = (7 - 3) / (4 - 2) = 4/2 = 2

Step 2: Find c using one point
y = 2x + c
3 = 2(2) + c
3 = 4 + c
c = -1

Step 3: Write equation
y = 2x - 1
📊 Parallel and Perpendicular Lines
Parallel Lines:
Parallel lines have the SAME gradient.

text
m₁ = m₂
Perpendicular Lines:
The product of perpendicular gradients = -1.

text
m₁ × m₂ = -1
Example 6: Perpendicular Lines
Problem: Find the gradient perpendicular to m = 2.

Solution:

text
m₁ × m₂ = -1
2 × m₂ = -1
m₂ = -1/2
✍️ Worked Examples
Example 7: Distance and Gradient
Problem: Find the distance and gradient between P(-2,-3) and Q(4,5).

Solution:

text
Distance:
d = √[(4 - (-2))² + (5 - (-3))²]
d = √[6² + 8²]
d = √[36 + 64] = √100 = 10

Gradient:
m = (5 - (-3)) / (4 - (-2))
m = 8/6 = 4/3
Example 8: Equation from Gradient and Point
Problem: Find the equation of a line with gradient 3 passing through (2,5).

Solution:

text
y = 3x + c
5 = 3(2) + c
5 = 6 + c
c = -1
y = 3x - 1
