## 📊 The Sine Rule

### The Formula:
a / sin A = b / sin B = c / sin C

text

**Or:**
sin A / a = sin B / b = sin C / c

text

### When to Use:
> **Use the Sine Rule when you know:**
> 1. Two sides and an angle opposite one of them
> 2. Two angles and one side

---

### Example 1: Finding a Side Using Sine Rule

**Problem:** In triangle ABC, A = 40°, B = 60°, and a = 10 cm. Find b.

**Solution:**
a / sin A = b / sin B
10 / sin 40° = b / sin 60°
b = (10 × sin 60°) / sin 40°
b = (10 × 0.8660) / 0.6428
b ≈ 13.47 cm

text

---

### Example 2: Finding an Angle Using Sine Rule

**Problem:** In triangle ABC, a = 10 cm, b = 15 cm, and A = 40°. Find B.

**Solution:**
a / sin A = b / sin B
10 / sin 40° = 15 / sin B
sin B = (15 × sin 40°) / 10
sin B = (15 × 0.6428) / 10
sin B = 0.9642
B = sin⁻¹(0.9642)
B ≈ 74.62°

text

## 📊 The Cosine Rule

### The Formula:
a² = b² + c² - 2bc cos A
b² = a² + c² - 2ac cos B
c² = a² + b² - 2ab cos C

text

### When to Use:
> **Use the Cosine Rule when you know:**
> 1. Two sides and the included angle
> 2. All three sides

---

### Example 3: Finding a Side Using Cosine Rule

**Problem:** In triangle ABC, b = 8 cm, c = 6 cm, and A = 50°. Find a.

**Solution:**
a² = b² + c² - 2bc cos A
a² = 8² + 6² - 2(8)(6) cos 50°
a² = 64 + 36 - 96 cos 50°
a² = 100 - 96 × 0.6428
a² = 100 - 61.71
a² = 38.29
a = √38.29
a ≈ 6.19 cm

text

---

### Example 4: Finding an Angle Using Cosine Rule

**Problem:** In triangle ABC, a = 7 cm, b = 8 cm, and c = 9 cm. Find A.

**Solution:**
a² = b² + c² - 2bc cos A
7² = 8² + 9² - 2(8)(9) cos A
49 = 64 + 81 - 144 cos A
49 = 145 - 144 cos A
144 cos A = 145 - 49
144 cos A = 96
cos A = 96/144
cos A = 2/3
A = cos⁻¹(2/3)
A ≈ 48.19°

text

## 📊 Area of a Triangle Using Sine

### The Formula:
Area = ½ ab sin C

text

**Where:**
- a and b are two sides
- C is the included angle between them
A
/
/
/

/
/__________
B a C

text

**Area = ½ ac sin B = ½ bc sin A = ½ ab sin C**

---

### Example 5: Finding Area Using Sine

**Problem:** In triangle ABC, a = 6 cm, b = 8 cm, and C = 60°. Find the area.

**Solution:**
Area = ½ ab sin C
Area = ½ × 6 × 8 × sin 60°
Area = 24 × 0.8660
Area ≈ 20.78 cm²

text

## 📊 Relationship with Pythagoras

### Important Connection:

If A = 90°:
a² = b² + c² - 2bc cos 90°
a² = b² + c² - 0
a² = b² + c²

text

Which is **Pythagoras' Theorem!**
