# Introduction to Quadratic Equations

## 🎯 What is a Quadratic Equation?

A quadratic equation has the variable raised to the power of 2.

**Standard Form:** `ax² + bx + c = 0`

---

## 📝 Factoring Method

### Example: Solve x² - 9 = 0
x² - 9 = 0
(x - 3)(x + 3) = 0
x = 3 or x = -3

text

---

## 📝 Quadratic Formula Method

### The Formula:
x = [-b ± √(b² - 4ac)] / 2a

text

### Example: Solve 2x² + 5x - 3 = 0
a = 2, b = 5, c = -3

x = [-5 ± √(25 - 4(2)(-3))] / 4
x = [-5 ± √49] / 4
x = [-5 ± 7] / 4

x = 0.5 or x = -3

text

## 🌍 Real-Life Application

**Projectile Motion:** A ball thrown upward follows: `h(t) = -16t² + 64t`

When does it hit the ground? (h = 0)
-16t² + 64t = 0
-16t(t - 4) = 0
t = 0 or t = 4

text

**Answer:** After 4 seconds
