# Introduction to Functions

## 🎯 What is a Function?

A **function** is a special relationship where each input has exactly **one** output.

Think of a function as a **machine**:
- You put something in (input)
- The machine processes it
- You get something out (output)

### The Key Rule:
Each INPUT (x) → Exactly ONE OUTPUT (y)

text

---

## 📚 The Function Machine
┌─────────┐
│ │
x ──► f(x) ──► y = f(x)
│ │
└─────────┘

text

**Example:** `f(x) = 2x + 3`

| Input (x) | Output f(x) |
|-----------|-------------|
| x = 1 | f(1) = 2(1) + 3 = 5 |
| x = 2 | f(2) = 2(2) + 3 = 7 |
| x = 3 | f(3) = 2(3) + 3 = 9 |

---

## 🔑 Function Notation

**Standard Form:** `f(x)`

**Read as:** "f of x"

**Examples:**
- `f(x) = 2x + 3`
- `g(x) = x² - 1`
- `h(x) = 3x - 5`

### Evaluating Functions:
f(x) = 2x + 3
f(4) = 2(4) + 3 = 11

text

## 🔍 Identifying Functions

### The Vertical Line Test:
If a vertical line intersects a graph at **more than one point**, it is **NOT** a function.
FUNCTION (✔️) NOT A FUNCTION (❌)
│ │
/│\ /│
/ │ \ / │
/ │ \ / │
/ │ \ / │ \

text

---

### Examples:

**✔️ This is a FUNCTION:**
y = 2x + 1

text
Each x has exactly one y-value.

**❌ This is NOT a FUNCTION:**
x = y²

text
When x = 4, y = 2 and y = -2 (two outputs!)

---

## 📊 Domain and Range

| Term | Definition | Example |
|------|------------|---------|
| **Domain** | All possible input values (x-values) | All real numbers |
| **Range** | All possible output values (y-values) | All real numbers |

### Example: `f(x) = x²`
- **Domain:** All real numbers (any number can be squared)
- **Range:** y ≥ 0 (squares are never negative)

---

## 📝 Types of Functions

### 1. Linear Function
f(x) = mx + b

text
- Graph: Straight line
- Example: `f(x) = 2x + 1`

### 2. Quadratic Function
f(x) = ax² + bx + c

text
- Graph: Parabola (U-shape)
- Example: `f(x) = x² - 4`

### 3. Constant Function
f(x) = c

text
- Graph: Horizontal line
- Example: `f(x) = 5`

### 4. Absolute Value Function
f(x) = |x|

text
- Graph: V-shape
- Example: `f(x) = |x - 2|`

## ✍️ Evaluating Functions

### Example 1: Basic Evaluation

**Problem:** Given `f(x) = 3x - 2`, find `f(4)`

**Solution:**
f(4) = 3(4) - 2
f(4) = 12 - 2
f(4) = 10

text

---

### Example 2: With Exponents

**Problem:** Given `f(x) = x² + 2x - 1`, find `f(3)`

**Solution:**
f(3) = 3² + 2(3) - 1
f(3) = 9 + 6 - 1
f(3) = 14

text

---

### Example 3: With Fractions

**Problem:** Given `f(x) = (x + 3)/2`, find `f(7)`

**Solution:**
f(7) = (7 + 3)/2
f(7) = 10/2
f(7) = 5

text

---

### Example 4: Piecewise Function

**Problem:** Given `f(x) = {x² if x ≥ 0, -x if x < 0}`, find `f(2)` and `f(-2)`

**Solution:**
f(2): 2 ≥ 0, so use x² = 4
f(-2): -2 < 0, so use -x = 2

text

## 📈 Graphing Functions

### Steps to Graph a Function:
1. Create a table of values (x, y)
2. Plot the points on a coordinate plane
3. Connect the points (if linear)

### Example: Graph `f(x) = 2x - 1`

| x | f(x) | Point |
|---|------|-------|
| -2 | -5 | (-2, -5) |
| -1 | -3 | (-1, -3) |
| 0 | -1 | (0, -1) |
| 1 | 1 | (1, 1) |
| 2 | 3 | (2, 3) |

Plot these points and draw a line through them.

## 🚨 Common Mistakes

### Mistake 1: Confusing Domain and Range

| ❌ WRONG | ✅ CORRECT |
|----------|-----------|
| Domain is y-values | Domain is x-values (inputs) |
| Range is x-values | Range is y-values (outputs) |

---

### Mistake 2: Forgetting the Vertical Line Test

Always check if a vertical line would intersect the graph in more than one place.

---

### Mistake 3: Not Checking Both Domains

For piecewise functions, check which piece applies for each input value.

## 📊 Summary

### Key Points:
1. **Functions** have exactly one output for each input
2. **Function notation:** `f(x)` means "f of x"
3. **Domain:** All possible inputs (x-values)
4. **Range:** All possible outputs (y-values)
5. **Vertical Line Test:** If a vertical line crosses a graph more than once, it's NOT a function

### Types of Functions:
| Type | Example | Graph Shape |
|------|---------|-------------|
| Linear | `f(x) = 2x + 1` | Straight line |
| Quadratic | `f(x) = x²` | Parabola (U-shape) |
| Constant | `f(x) = 5` | Horizontal line |
| Absolute Value | `f(x) = |x|` | V-shape |
