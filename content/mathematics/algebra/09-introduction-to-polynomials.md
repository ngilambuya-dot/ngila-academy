# Introduction to Polynomials

## 🎯 What is a Polynomial?

A **polynomial** is an expression made up of variables, coefficients, and exponents, combined using addition, subtraction, and multiplication.

### The General Form:
P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀

text

**Examples of Polynomials:**
- `3x² + 2x - 1` ✅
- `5x³ - 4x + 7` ✅
- `x⁴ - 3x² + 2` ✅
- `x² + 1` ✅

**NOT Polynomials:**
- `x⁻² + 3` ❌ (negative exponent)
- `√x + 2` ❌ (variable under radical)
- `1/x + 3` ❌ (variable in denominator)

---

## 🔑 Key Vocabulary

| Term | Definition | Example |
|------|------------|---------|
| **Term** | A single part of a polynomial | `3x²`, `-2x`, `5` |
| **Coefficient** | The number multiplying the variable | `3` in `3x²` |
| **Variable** | The letter representing a number | `x` in `3x²` |
| **Exponent** | The power of the variable | `2` in `3x²` |
| **Degree** | The highest exponent in the polynomial | `2` in `3x² + 2x - 1` |
| **Constant** | A term without a variable | `-1` in `3x² + 2x - 1` |
| **Leading Coefficient** | Coefficient of the highest degree term | `3` in `3x² + 2x - 1` |

---

## 📊 Classifying Polynomials

### By Number of Terms:

| Name | Number of Terms | Example |
|------|-----------------|---------|
| **Monomial** | 1 term | `3x²` |
| **Binomial** | 2 terms | `3x² + 2x` |
| **Trinomial** | 3 terms | `3x² + 2x - 1` |
| **Polynomial** | 4+ terms | `x⁴ + 2x³ - x² + 3x - 5` |

### By Degree:

| Degree | Name | Example |
|--------|------|---------|
| 0 | Constant | `5` |
| 1 | Linear | `2x + 3` |
| 2 | Quadratic | `3x² + 2x - 1` |
| 3 | Cubic | `x³ - 4x² + 3x - 2` |
| 4 | Quartic | `x⁴ - 3x² + 2` |
| 5 | Quintic | `x⁵ - 2x³ + x - 1` |

## ✍️ Adding and Subtracting Polynomials

### Rule: Combine like terms (same variable and same exponent)

### Example 1: Adding Polynomials

**Problem:** Add `(3x² + 2x - 1) + (2x² - 3x + 5)`

**Solution:**
(3x² + 2x - 1) + (2x² - 3x + 5)
= (3x² + 2x²) + (2x - 3x) + (-1 + 5)
= 5x² - x + 4

text

---

### Example 2: Subtracting Polynomials

**Problem:** Subtract `(4x² - 3x + 2) - (2x² + 5x - 3)`

**Solution:**
(4x² - 3x + 2) - (2x² + 5x - 3)
= 4x² - 3x + 2 - 2x² - 5x + 3
= (4x² - 2x²) + (-3x - 5x) + (2 + 3)
= 2x² - 8x + 5

text

---

### Example 3: Vertical Addition

**Problem:** Add `3x³ - 2x² + 5` and `x³ + 4x² - 3x + 2`

**Solution:**
3x³ - 2x² + 0x + 5

x³ + 4x² - 3x + 2
───────────────────────
4x³ + 2x² - 3x + 7

text

---

## ✍️ Multiplying Polynomials

### Example 4: Monomial × Polynomial

**Problem:** Multiply `3x(2x² - 4x + 1)`

**Solution:**
3x(2x² - 4x + 1)
= 3x(2x²) - 3x(4x) + 3x(1)
= 6x³ - 12x² + 3x

text

---

### Example 5: Binomial × Binomial (FOIL)

**Problem:** Multiply `(x + 3)(x - 2)`

**Solution:**

| Letter | Operation | Result |
|--------|-----------|--------|
| **F** | First: x·x | x² |
| **O** | Outer: x·(-2) | -2x |
| **I** | Inner: 3·x | 3x |
| **L** | Last: 3·(-2) | -6 |
(x + 3)(x - 2) = x² - 2x + 3x - 6 = x² + x - 6

text

---

### Example 6: Binomial × Trinomial

**Problem:** Multiply `(2x + 1)(x² - 3x + 4)`

**Solution:**
(2x + 1)(x² - 3x + 4)
= 2x(x² - 3x + 4) + 1(x² - 3x + 4)
= (2x³ - 6x² + 8x) + (x² - 3x + 4)
= 2x³ - 5x² + 5x + 4

text

---

### Example 7: Special Products

**Difference of Squares:**
(a + b)(a - b) = a² - b²

text
Example: `(x + 3)(x - 3) = x² - 9`

**Perfect Square:**
(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²

text
Example: `(x + 3)² = x² + 6x + 9`

## ✍️ Dividing Polynomials

### Example 8: Long Division

**Problem:** Divide `(x² + 5x + 6) ÷ (x + 2)`

**Solution:**
x + 3
─────────────
x+2 | x² + 5x + 6
-(x² + 2x)
──────────
3x + 6
-(3x + 6)
────────
0

text

**Answer:** `x + 3`

---

### Example 9: Long Division with Remainder

**Problem:** Divide `(x² + 4x + 5) ÷ (x + 1)`

**Solution:**
x + 3
─────────────
x+1 | x² + 4x + 5
-(x² + x)
──────────
3x + 5
-(3x + 3)
────────
2

text

**Answer:** `x + 3 + 2/(x + 1)`

## 📊 Operations Summary

| Operation | Method | Example |
|-----------|--------|---------|
| **Addition** | Combine like terms | (3x² + 2x) + (x² - x) = 4x² + x |
| **Subtraction** | Combine like terms | (3x² + 2x) - (x² - x) = 2x² + 3x |
| **Multiplication** | Distribute/FOIL | 3x(x + 2) = 3x² + 6x |
| **Division** | Long division | (x² + 3x + 2) ÷ (x + 1) = x + 2 |

## 🌍 Real-Life Applications

### Application 1: Volume

> A box with length (x+3), width (x+2), height (x+1)
> **Volume** = (x+3)(x+2)(x+1) = x³ + 6x² + 11x + 6

### Application 2: Area

> A rectangle with length (2x+3) and width (x-1)
> **Area** = (2x+3)(x-1) = 2x² + x - 3

### Application 3: Projectile Motion

> Height of a ball: h(t) = -16t² + 64t + 32
> This is a polynomial of degree 2

## 🚨 Common Mistakes

### Mistake 1: Forgetting to Distribute

| ❌ WRONG | ✅ CORRECT |
|----------|-----------|
| `3x(x + 2) = 3x + 2` | `3x(x + 2) = 3x² + 6x` |

---

### Mistake 2: Sign Errors in Subtraction

| ❌ WRONG | ✅ CORRECT |
|----------|-----------|
| `(3x² - 2x) - (x² + x) = 2x² - x` | `(3x² - 2x) - (x² + x) = 2x² - 3x` |

---

### Mistake 3: Missing Terms in Division

Always include placeholders (0x) for missing terms.

## 📊 Summary

### Key Points:
1. **Polynomials** are expressions with non-negative integer exponents
2. **Degree** = highest exponent
3. **Classify** by number of terms (monomial, binomial, trinomial)
4. **Add/Subtract:** Combine like terms
5. **Multiply:** Distribute and combine
6. **Divide:** Use long division
